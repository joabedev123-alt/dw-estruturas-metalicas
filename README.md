# DW Estruturas Metálicas — Landing Page Oficial

Landing page de alta conversão e site institucional para a **DW Estruturas Metálicas** (Curitiba e Região Metropolitana).

## 🚀 Sobre o Projeto

A **DW Estruturas Metálicas** projeta, fabrica e instala estruturas metálicas sob medida, do projeto ao acabamento, com fábrica própria no bairro Xaxim, Curitiba/PR, e mais de 6 anos de atuação.

### ✨ Funcionalidades e Destaques
- **Design Industrial Ultra Premium:** Identidade visual com azul-escuro profundo, grafite e laranja de destaque estrutural.
- **Alta Conversão no WhatsApp:** Formulário curto com formatação automática e direcionamento direto para o WhatsApp oficial `(41) 99894-1829`.
- **100% Mobile First:** Menu lateral em gaveta (drawer) com `100dvh`, alvos de toque acessíveis e gestos de toque (*swipe*) na galeria.
- **Portfólio com Fotos Reais:** Galeria categorizada de Mezaninos, Pergolados e Gradis com visualizador (*lightbox*) em tela cheia.
- **SEO Local Completo:** Tags semânticas, Schema.org LocalBusiness, Open Graph, Sitemap e Robots.txt.
- **Crédito Interativo:** Produzida com 🧡 por [CAMALY](https://camaly.com.br/).

## 💻 Como Executar Localmente

1. Clone ou baixe este repositório.
2. Inicie um servidor estático local:
   ```bash
   npx serve . -l 5050
   ```
   ou
   ```bash
   npm start
   ```
3. Abra no navegador: [http://localhost:5050](http://localhost:5050)
